# Точное открытие PPTX и офисный редактор

## Статус

Подготовлен адаптер ONLYOFFICE Docs. Он не включается без рабочего Document Server и секрета JWT. Пока переменные не заданы, Apollo использует прежний локальный просмотрщик. Проверки адаптера с SQLite и подставным сервером проходят; визуальная совместимость с реальным ONLYOFFICE и презентацией пользователя ещё не проверена. Нельзя считать проблему отображения решённой до подключения и приёмки.

## Почему требуется движок

Текущий HTML-просмотрщик не реализует формат PPTX полностью: он заменяет диаграммы заглушками и не воспроизводит все схемы, шрифты, переносы и геометрию. Встроенный ONLYOFFICE работает с презентацией своим офисным движком; доступны редактирование текста, изображения, таблицы, диаграммы, фигуры, размеры, повороты, порядок объектов и операции со слайдами. Это отдельный продукт, поэтому абсолютное совпадение с каждой версией PowerPoint не гарантируется. Шрифты исходной презентации должны быть установлены на Document Server с соблюдением их лицензий.

## Развёртывание

Нужны отдельный Linux-сервер с Docker Compose, домен редактора с DNS на этот сервер и открытые порты 80/443. Cloudflare Workers, на которых размещён Apollo, не запускают контейнер Document Server.

1. Скопировать каталог `deploy/onlyoffice` на сервер и `env.example` в `.env`.
2. Указать реальный `DOCS_HOST`, например домен собственного редактора, без схемы URL. Создать случайный секрет: `openssl rand -base64 48`. Записать его в `JWT_SECRET` в `.env`; не публиковать `.env` и не отправлять секрет в чат.
3. Проверить условия использования ONLYOFFICE и соответствие выбранной редакции требованиям встраивания сервиса. В комплекте сохранён оригинальный интерфейс редактора.
4. Выполнить `docker compose up -d`. Caddy выдаст HTTPS-сертификат для настроенного домена. После приёмки зафиксировать протестированную версию/дайджест образа вместо `latest`.
5. Проверить `https://<домен>/healthcheck` и `https://<домен>/web-apps/apps/api/documents/api.js`.
6. В переменных среды Apollo задать `ONLYOFFICE_URL=https://<домен>/` и `ONLYOFFICE_JWT_SECRET` — тот же секрет, что на Document Server. Можно отдельно задать случайный `APOLLO_OFFICE_SIGNING_SECRET` (иначе применяется производный ключ доступа к файлам). Секреты только в серверном окружении.
7. Повторно опубликовать Apollo после настройки окружения и проверить реальную презентацию. Сам сервер и браузер должны обращаться друг к другу по HTTPS; Document Server должен доставать Apollo по публичному адресу.

Официальные руководства:
- https://api.onlyoffice.com/docs/docs-api/get-started/basic-concepts/
- https://api.onlyoffice.com/docs/docs-api/usage-api/callback-handler/
- https://github.com/ONLYOFFICE/Docker-DocumentServer

## Что реализовано в Apollo

- Вход по прежнему логину/паролю. Файл доступен редактору по подписанной ссылке на конкретную версию. Ссылка ограничена временем и повторно проверяет членство в компании.
- Подписанная конфигурация, JWT callback и проверка адреса сохранённого файла. Файлы не отправляются на публичный демонстрационный сервер.
- Сохранение через существующий механизм ревизий и R2; прошлые версии остаются доступными. Повтор одного callback не создаёт дубль версии.
- Роль наблюдателя и исторические версии открываются только для просмотра. Отозванные права запрещают загрузку и сохранение.
- Конфликт с другим сеансом не перезаписывает файл. Пользователь получает сообщение и может скачать свою копию из меню офисного редактора.
- Отдельная политика безопасности встроенного редактора допускает только настроенный домен Document Server; политика остального приложения не расширяется.
- Компактная офисная панель, открытие режима редактирования, статус записи в Apollo и предупреждение при выходе с несохранёнными изменениями.
- Сеанс ограничен 12 часами; при длительной работе перед его окончанием сохранить/скачать файл и открыть заново. Совместное редактирование между отдельными сеансами Apollo пока не включено.

## Приёмка после подключения

1. Открыть исходный PPTX пользователя и сравнить каждый слайд с PowerPoint: особенно диаграммы, шрифты, переносы, таблицы, фон, изображения, группы и обрезку.
2. Отредактировать текст, передвинуть и растянуть объект, изменить диаграмму, добавить изображение, создать и переставить слайд.
3. Сохранить из офисного редактора (Ctrl+S), дождаться сообщения «Сохранена версия», закрыть и открыть презентацию. Скачать и проверить её в PowerPoint.
4. Проверить роль наблюдателя, историческую версию и два конфликтующих сеанса.
5. Проверить настольный и узкий экран, меню, отсутствие дублей, отступы и читаемость. Тесты адаптера: `node --test tests/presentation-office.test.mjs`.
