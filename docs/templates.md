# Специализации и рабочие шаблоны

Apollo Task 0.6. Набор предназначен для небольших производственных и промышленных компаний. Это практическая группировка функций, а не статистический рейтинг распространённости отделов. В небольшой организации несколько направлений может вести один сотрудник.

| Направление | Шаблоны |
| --- | --- |
| Общие | Заявка; Протокол встречи; Запрос на изменение; Проверка актуальности документа |
| Управление | Карточка управленческого решения; Матрица ответственности; Контрольная точка проекта |
| Продажи | Обработка запроса клиента; Расчёт коммерческого предложения; Передача заказа в работу |
| Маркетинг | Заявка на маркетинговый материал; План продвижения; Отчёт о маркетинговой активности |
| Производство | Маршрут выполнения работ; Карта рабочей операции; Передача смены |
| Технический отдел | Техническое задание; Проверка технической документации; Реестр технической документации |
| Снабжение | Заявка на закупку; Сравнение предложений поставщиков; Передача работ подрядчику |
| Склад | Приёмка на склад; Комплектация заказа; Сверка складских остатков |
| Логистика | Подготовка к отгрузке; Заявка на перевозку; Отклонение при доставке |
| Качество | Входной контроль; Протокол контроля качества; Несоответствие и корректирующие действия; Контроль рабочей операции |
| Оборудование | Карточка оборудования; Заявка на обслуживание; План обслуживания оборудования |
| Бухгалтерия | Запрос первичных документов; Сверка взаиморасчётов; Закрытие учётного периода |
| Финансы | Заявка на оплату; Бюджет подразделения; План-факт анализ |
| Юридический отдел | Согласование договора; Контроль договорных обязательств; Запрос в юридический отдел |
| Персонал | Заявка на подбор сотрудника; План адаптации сотрудника; Кадровый запрос |
| Охрана труда | Замечание по условиям работы; План мероприятий по охране труда; Разбор производственного инцидента |
| ИТ | Заявка на рабочие доступы; Обращение в ИТ; План изменения системы |
| Администрация | Заявка на административную услугу; Регистрация и передача документа; Контроль административного подрядчика |

Каждый шаблон содержит собственные поля, рабочие таблицы и блок следующих действий. Они создают внутренние рабочие документы, без заранее внесённых реквизитов, сотрудников, заказов и технических требований. Создание документа не добавляет сотрудников, проекты или задачи.

## Основание для группировки

В официальных материалах производственных и сервисных компаний представлены технические, коммерческие, финансовые, бухгалтерские, юридические, кадровые, качественные и обеспечивающие функции. Состав каталога адаптирован к межотдельным процессам небольшой компании.

- [Промышленные компоненты КАМАЗ: вакансии](https://industrial-kamaz.ru/about/karera/vakansii/vakansii.php) — конструкторская работа, продажи, качество, бюджетирование.
- [КАМСС: вакансии](https://kamaz.kamss.ru/company/vacancy/) — обслуживание, бухгалтерия и договорная работа.
- [НТК: специализации](https://www.ntk-corp.ru/career/vacancies/?specialization=17) — классификация направлений, включая ИТ, закупки, финансы, юристов и персонал.
