## Версия 0.9

Вход по выданным логину и паролю. На начальном экране только форма авторизации. Демо, самостоятельная регистрация, туры и восстановление на экране входа удалены. Новая компания получает пустое пространство: один настоящий администратор, пустая база знаний, без проектов, задач и сотрудников-примеров. Существующие записи не удаляются.

- Рабочие файлы: загрузка до 10 файлов за раз (25 МБ каждый), перетаскивание, отдельные карточки в базе знаний, вложения к страницам и вставка в текст редактора. Word, Excel, PowerPoint, OpenDocument, PDF, CSV/TSV, изображения, архивы и чертежи. Оригинальные файлы доступны только участникам компании.
- Файлы открываются внутри Apollo: DOCX — страницы, таблицы и изображения; XLSX/XLS/XLSM/ODS/CSV — листы и навигация по строкам и столбцам; PPTX — слайды, текст, изображения и таблицы; PDF — оригинальный документ. Поддерживаются изображения, RTF/TXT, ODT/ODP и список файлов ZIP. Старые DOC/PPT открываются в текстовом режиме. Для CAD текстовых форматов показывается исходный текст; DWG, TIFF, RAR и 7z пока скачиваются. Просмотр не редактирует файл, не вычисляет формулы и не воспроизводит анимацию. Сложные элементы оформления могут отличаться от Microsoft Office.
- Просмотрщик загружается с сервиса и обрабатывает файлы в браузере без публичных ссылок и передачи документов внешним конвертерам. Проверка доступа к оригиналу остаётся на сервере. Отдельная карточка загруженного файла сразу показывает содержимое; вложение открывается нажатием на название. Повторная загрузка старых файлов не нужна.
- Google Документы, Таблицы, Презентации и файлы Drive добавляются ссылкой в текст страницы или отдельной карточкой. Просмотр внутри Apollo запускается по нажатию; доступ определяется исходными настройками Google. Автоматической публикации или изменения разрешений нет.
- Навигация: одна шестерёнка настройки панели; настройки компании открываются по её названию. Подключение другой компании и повторяющиеся кнопки удалены.
- Глобальный поиск по документам (включая текст, шифры и теги), проектам, задачам, людям и шаблонам. Подсказки, недавние результаты и управление клавиатурой.
- Личный кабинет: фото с кадрированием, контакты, должность, зона ответственности, рабочий статус и собственные материалы. Настройки компании: логотип, описание и контакты; изменение доступно владельцу. Изображения хранятся в R2 и выдаются только участникам компании.
- Дашборд редактируется прямо на странице: перетаскивание, стрелки, скрытие, добавление и изменение ширины блоков, готовые раскладки и отмена.
- Единые элементы интерфейса: чекбоксы с состояниями выбора и фокусом, выпадающие списки, отступы, выравнивание SVG-иконок. Фильтры базы знаний адаптируются под ширину экрана и сворачиваются на телефоне.
- Обзор: семь блоков с реальными показателями, сроками, загрузкой, согласованиями и актуальностью документов. Личные настройки видимости, порядка, колонок и области «Моя работа / Вся компания» хранятся на сервере отдельно от данных компании.
- Знания: разделы и папки, реестр, поиск по содержимому, шифру и тегам, фильтры, сортировка, постраничный вывод, архив и массовое перемещение. Паспорт документа содержит тип, шифр, редакцию, срок проверки, теги и ссылки на связанные документы.
- Редактор: текст, списки, таблицы, комментарии, история версий, восстановление, вложения до 25 МБ и внутреннее согласование конкретной версии.
- 56 шаблонов документов по задачам 17 направлений и общим процессам. Названия и содержание не привязаны к конкретной продукции. Бухгалтерия, финансы и юридический отдел имеют отдельные наборы. В каталоге также доступны пустой документ, две доски и реестр работ — 60 вариантов всего. Есть поиск, фильтр по специализации и предпросмотр перед созданием.
- 37 должностей с подразделениями и зонами ответственности. Организационная должность отделена от прав owner/editor/viewer. При создании сотрудника можно выбрать должность и изменить предложенные поля.
- Проекты, задачи, доски, реестры, ссылки, личные кабинеты, настраиваемая боковая панель и экспорт/импорт JSON.

## Доступ и хранение

Аккаунты и сессии проверяются сервером; пароли хешируются PBKDF2 с индивидуальной солью. Cookie HttpOnly, Secure, SameSite=Lax. Доступ к данным требует членства в конкретной компании. Лимиты попыток защищают форму входа. Смена пароля завершает другие сеансы. Для сотрудников создаются одноразово показываемые временные пароли с обязательной заменой при первом входе.

Данные хранятся в Cloudflare D1, файлы — в R2. Сохранение проверяет номер ревизии; конфликт не перезаписывает чужие изменения. Личные настройки не входят в общие записи компании. Учётные данные не содержатся в исходном коде, GitHub Pages или localStorage.

Временный маршрут первичной выдачи аккаунта удалён после настройки. `APOLLO_GATEWAY_ORIGIN` разрешает HTTPS POST формы с принадлежащего владельцу GitHub Pages. Данные входа не передаются в URL.

## Проверка и сборка

```sh
npm run check
npm run gateway
npm run build
```

GitHub Pages публикует экран входа из `web/`. Серверная версия развёрнута отдельно: статический GitHub Pages не выполняет API и не хранит корпоративные данные.
