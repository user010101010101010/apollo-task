# Apollo Task

Интерактивный MVP рабочего пространства небольшой команды. Структура и основные UX-паттерны вдохновлены Confluence: пространства, дерево знаний, страницы, обсуждения и единый поиск. Собственная визуальная система Apollo Task, русский интерфейс, адаптивная версия.

## Возможности

- Обзор рабочего пространства: недавние страницы, пространства, задачи и изменения команды.
- Создание пространств и страниц, 6 шаблонов, визуальный редактор с форматированием.
- Ответственные за страницы, статусы актуальности, комментарии, избранное.
- История версий с просмотром и восстановлением.
- Поиск по содержимому страниц, задачам и ответственности сотрудников (Ctrl/⌘ K).
- Задачи: создание, редактирование, удаление, сроки, приоритеты, исполнители, связанные страницы.
- Доска с переносом карточек и списковый вид; фильтры личных и командных задач.
- Карточки сотрудников: обязанности, команда, контакты и текущие задачи.
- Экспорт/импорт JSON и восстановление первоначальных демо-данных.
- Адаптивный интерфейс, клавиатурная навигация, фокус в диалогах, поддержка reduced motion.

## Запуск

Зависимостей и сборки для запуска нет. Нужен статический HTTP-сервер: модули JavaScript не следует открывать через file://.

```bash
npm start
# http://localhost:3000
```

Или разместите содержимое `dist/` на любом статическом хостинге. Относительные пути поддерживают размещение в подпапке GitHub Pages. Маршрутизация работает через URL hash.

```bash
npm run check
npm run build
```

`build` проверяет JavaScript и структуру статического приложения; готовые файлы уже находятся в `dist/`.

## Хранение данных и ограничения

Это **клиентский MVP**, не готовая серверная система для корпоративных данных. Состояние сохраняется в localStorage текущего браузера под ключом `apollo-task.v1`. Начальное пространство Apollo Studio и сотрудники — демонстрационные, адреса используют example.com. Изменения на разных устройствах не синхронизируются. Ссылка на созданную страницу не переносит её содержимое другому пользователю.

Карточка сотрудника не является аккаунтом и не отправляет приглашение. Нет серверной авторизации, ролевого разграничения доступа, общего редактирования, отправки почты и серверных резервных копий. Используйте экспорт JSON для сохранения своей работы и переноса данных. Очистка данных браузера удалит локальные изменения.

Пользовательские строки экранируются, HTML редактора очищается по списку разрешённых тегов и безопасных ссылок; JSON проверяется перед импортом. Экспорт содержит все данные текущего демо-пространства. Подключение Google Fonts необязательно: есть системные шрифты для работы без внешнего ресурса. Для будущего корпоративного размещения шрифт можно хранить локально.

## Структура

```text
dist/
  index.html     # точка входа
  styles.css     # визуальная система и адаптивность
  app.js         # экраны, редактор и взаимодействия
  data.js        # модель, демо-данные и поиск
  icons.js       # локальные SVG-иконки
  favicon.svg    # знак Apollo Task
tests/
  domain.test.js # валидация импорта, поиск, даты и статусы
scripts/
  build.mjs      # проверка статического приложения
```

## Следующий этап

Серверная база данных и API, организации и учётные записи, приглашения, проверяемые на сервере права доступа, совместная работа, вложения и резервное копирование. Текущий интерфейс можно использовать для пользовательских тестов перед разработкой этих возможностей.

Дизайн использует знакомые паттерны корпоративной wiki, не содержит код, логотипы и материалы Atlassian.
